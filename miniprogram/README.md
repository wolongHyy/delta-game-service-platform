# 微信开发者工具测试入口

这个目录不是重写网页版，而是给微信开发者工具导入的最小小程序壳，用来加载 Next.js 网页版。

1. 先在 `delta_app` 双击 `start.bat`，等服务显示可访问。
2. 微信开发者工具导入 `C:\Users\1\Desktop\VOID\delta_app\miniprogram`。
3. 开发者工具里打开“详情 → 本地设置”，勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
4. 模拟器默认地址是当前电脑局域网 IP；手机预览时手机和电脑必须在同一 Wi-Fi。
5. 如果电脑 IP 变化，进入小程序“调试”页修改服务地址。
6. “调试”页里有“三端入口”：点单是用户端，`/fighter` 是打手端登录页，`/admin` 是管理端。本地测试管理端用账号 `admin`、密码 `admin123` 登录。
7. 当前默认服务地址为 `http://192.168.31.178:3000`。电脑 IP 变化后，请同步修改 `utils/config.js`，或在“调试”页覆盖地址。
8. 局域网 HTTP 地址只适合开发者工具和同一 Wi-Fi 下的测试；微信体验版/正式版的 `web-view` 必须使用已备案的 HTTPS 域名，并在小程序后台配置“业务域名”。
